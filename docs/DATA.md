# Правила маршрута

Цели в goals.json содержат целевые темы, prerequisites добавляются автоматически. catalog.json содержит 6 тем с текстами, практикой, временем и источниками. В questions.json 36 вопросов: 18 диагностических и 18 контрольных.

Граф: Python → pandas → ML; статистика → ML; Python → LLM. SQL — отдельная тема. Диагностика охватывает все темы; маршрут показывает только цель и её prerequisites.

Освоение: минимум 2/3 ответов верны и все prerequisites освоены. Тест проверяется атомарно, только при полном наборе ответов. Повторная диагностика закрыта; доступны контрольные по нужным темам. Повторная контрольная может снизить статус, тогда зависимые темы теряют освоение и требуют повторного подтверждения.

Времена 45–60 минут — авторская оценка, не результат измерения. Профили и история сохраняются локально. Для новой цели создайте отдельный профиль; смены цели в существующем профиле пока нет.
